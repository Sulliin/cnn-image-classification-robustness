# CNN Image Classification Robustness Under Image Degradation
This repository contains the experimental notebooks for an MSc dissertation project.
# Experiments
`MainExperiment.ipynb`: controlled low-resolution degradation on the Intel Image Classification dataset, including ResNet18 and Swin2SR preprocessing.
`ExDark_CLAHE.ipynb`: low-light image classification on the ExDark dataset, including CLAHE enhancement.
# Datasets
The datasets are not included in this repository. They should be obtained from their original public sources.
# Requirements
Python, PyTorch, torchvision, OpenCV, Pillow, matplotlib, pandas, and Jupyter Notebook.
